# Security policy

We take security seriously. Please report suspected vulnerabilities privately to
the maintainers rather than opening a public issue.

See [`docs/SECURITY.md`](docs/SECURITY.md) for the full security model, controls
and production checklist.

## Supported scope

- Latest `main` branch.

## What to include in a report

- Affected endpoint/component and environment.
- Reproduction steps or proof of concept.
- Impact assessment (data exposure, privilege escalation, quota bypass, etc.).
- Any suggested remediation.

Please allow reasonable time for a fix before disclosure.
