# ADR-006: Replace the embedded UPI gateway with YouPI-PG V2

- **Status:** Accepted
- **Date:** 2026-11-13

## Context

ExamDump Pro collected plan payments into its own UPI account without a payment
gateway. The application polled a Gmail mailbox for bank alerts, parsed them,
matched them against orders by a unique 0-99 paise amount suffix, and settled
internally. That worked, but it made a payment gateway out of a study
application: the observer, the parser, the matcher, the risk rules and the
operator dashboard all lived inside the same process and database as the exam
product.

Three consequences made this the wrong place for it:

1. **Blast radius.** A bug in settlement shared a deploy path, a database and a
   process with the product users pay for.
2. **Security surface.** The gateway needed Gmail OAuth credentials, an
   encryption key and notification-ingest endpoints reachable in the same
   application that serves exam content.
3. **Operational coupling.** Restarting the API to ship a product fix also
   restarted payment polling.

## Decision

Remove the embedded gateway from ExamDump Pro and run YouPI-PG V2 as a
standalone payment gateway on the same host, in its own container, with its own
SQLite database and its own reverse-proxy entry point.

ExamDump keeps only what a payment *consumer* needs: the generic `'upi'`
payment-method enum used by the Razorpay and HyperSwitch adapters, and the
existing settlement path in `subscription.service.ts`.

## Consequences

**Retained deliberately, and not to be deleted by a future cleanup:**

- `apps/api/src/services/payments/adapter.ts` and `razorpay.adapter.ts` — `'upi'`
  here is a payment *method* (a card network also offers UPI), not the retired
  gateway.
- `apps/api/src/services/hyperswitch.client.ts` — the active provider.
- `apps/api/src/lib/secretbox.ts` — general authenticated encryption, not
  UPI-specific.
- Migrations `0006`-`0008` and the seven `upi_*` tables. Deleting migration files
  breaks the journal chain; the tables are empty and dropping them is a separate,
  explicitly approved step.

**Removed:** 4 routes, the `services/upi/` subsystem, the UPI schema module, the
OAuth CLI, 5 test suites, 3 web components and 2 guides. The three
gateway-exclusive Doppler secrets (`UPI_GOOGLE_CLIENT_ID`,
`UPI_GOOGLE_CLIENT_SECRET`, `UPI_SECRETS_KEY`) were deleted from `prd`.

**Why the tables stay for now:** a rollback to the previous API image must still
find the schema it was built against. Dropping them is deferred until YouPI-PG
has been live and stable long enough that rollback is no longer plausible.

**Trade-off accepted:** UPI collection is unavailable between this change and
YouPI-PG going live. Card checkout is unaffected.
